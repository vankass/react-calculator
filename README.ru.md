# 🧮 Calculator

🇬🇧 [English version](README.md)

Простое и удобное приложение-калькулятор.

Учебный проект, созданный для практики работы с **React** и современным **JavaScript**.

## 🚀 Особенности

* Выполнение основных арифметических операций
* Поддержка ввода с клавиатуры
* История вычислений
* Копирование текущего результата в буфер обмена

## 🛠 Технологии

* **HTML5**
* **CSS3**
* **JavaScript**
* **React**
* **Vite**
